# CL-II Practicals

This repository contains the practical assignments completed for **Computer Laboratory – II (CL-II)**.

The practicals are divided into two sections:
- **UI/UX Design:** 6 practicals created using Figma.
- **Industrial Internet of Things (IIoT):** 5 practicals implemented using Arduino and Tinkercad.
